# 非麦当劳食物的估算规范

用户不会每顿都吃麦当劳。别的饭让他说一句就行，你来估。

## 怎么估

1. **拆成条目**：一句话里有几样就拆几样。"黄焖鸡米饭加一杯半糖奶茶" → 黄焖鸡米饭、半糖奶茶。
2. **定份量**：用户说了就按用户的；没说就按中国常见的一人份，写进名字里，如"肉包（2 个，约 200g）"。
3. **估热量和蛋白质**：按常见做法取中间值，取整数。不要给区间让用户自己选。
4. **说出前提**：回复时用一句话讲份量和做法假设，例如"按食堂一人份、米饭约 200g 估的"。
5. **记录**：`log add --source other`，名字里带份量。脚本会标成"AI 估算"。

## 常见参考（一人份，取中间值）

| 食物 | 热量 | 蛋白质 |
|---|---|---|
| 米饭一碗（约 200g） | 230 | 5 |
| 肉包一个（约 100g） | 230 | 9 |
| 豆浆一杯（250ml，微甜） | 110 | 7 |
| 牛肉面一大碗 | 550 | 25 |
| 黄焖鸡米饭 | 700 | 33 |
| 麻辣香锅（约 600g，不含米饭） | 900 | 35 |
| 半糖奶茶 500ml | 250～300 | 3 |
| 蔬菜沙拉（油醋汁） | 150 | 4 |
| 鸡胸肉 150g | 200 | 34 |
| 香蕉一根 | 90 | 1 |

这张表只是帮你校准量级，用户描述得更具体时按描述估。

## 不要做的事

- 不要把估算说成精确值，也不要和麦当劳官方营养数据混在一起不加区分。
- 用户说的不是食物（"开了一下午会"）就不记录，直接说明。
- 用户说"大概吃了一半""只喝了几口"，就按比例减。
- 用户纠正你（"那碗面很小"），用 `--replace` 重记，不要争。
